# C#. Практические задания по архитектуре программного приложения

Репозиторий содержит выполненные задания по дисциплине  
"Информационные системы и технологии. Архитектура программного приложения"  
(C#, 2 курс).

## Содержание

Каждое задание находится в отдельной папке:

T1_Library - Библиотека: учет книг, читателей, выдачи и возврата книг  
T2_Warehouse - Склады: учет товаров, складов, кладовщиков и поступлений  
T3_University - Университет: анализ успеваемости студентов по предметам и группам  
T4_Airline - Аэроперевозки: учет рейсов, аэропортов, отправлений и прибытий  
T5_Tickets - Авиабилеты: учет продажи билетов и подсчет выручки  
T6_Hospital - Журнал учета больных: учет пациентов, палат, врачей и состояния больных  
T7_Network - Компьютерная сеть: учет компьютеров, комнат, комплектующих и их типов  
T8_House - Жильцы: учет людей, квартир, вселения, выселения и коммунальных платежей  
T9_CarService - Автосервис: учет автомобилей, клиентов, мастеров и ремонтов  
T10_Taxi - Такси: учет автомобилей, водителей, клиентов и заказов
